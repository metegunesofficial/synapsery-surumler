## English

This repository distributes the signed installation packages and update information for Synapsery.

### Windows

1. In the **Assets** section of the latest release, download `Synapsery_<version>_x64-setup.exe` and run it. Administrator rights are not required.
2. If Windows shows "Windows protected your PC", select **More info > Run anyway**. This is needed only once.

A Microsoft Store version is in preparation and will install without this prompt once published.

Requirements: Windows 10 or 11, 64-bit.

### macOS

macOS packages will appear in the **Assets** section of a release when available.

1. Download `Synapsery_<version>_aarch64.dmg` for Apple Silicon or `Synapsery_<version>_x64.dmg` for Intel, open it, and drag Synapsery to the **Applications** folder.
2. Open Synapsery. If macOS reports that Apple could not verify it, select **Done** (do not move it to the Trash).
3. Go to **System Settings > Privacy & Security**, scroll down, and select **Open Anyway** next to "Synapsery was blocked". Confirm with **Open Anyway** and enter your Mac password.

This approval is needed only once. On macOS 14 and earlier, Control-click Synapsery and select **Open**.

If a DMG is reported as damaged, download it again from the official link on this page only. Do not open DMG files from other sources.

### Updates

Synapsery checks for new versions at startup. Updates download with a single click, are verified by signature, and install automatically.

## Türkçe

Bu depo, Synapsery'nin imzalı kurulum paketlerini ve güncelleme bilgisini dağıtır.

### Windows

1. En son sürümün **Assets** bölümünden `Synapsery_<sürüm>_x64-setup.exe` dosyasını indirip çalıştırın. Yönetici yetkisi gerekmez.
2. "Windows bilgisayarınızı korudu" uyarısı görünürse **Ek bilgi > Yine de çalıştır** seçeneğini seçin. Bu işlem yalnızca bir kez gerekir.

Microsoft Store sürümü hazırlanmaktadır; yayımlandığında bu uyarı olmadan kurulabilecektir.

Gereksinimler: Windows 10 veya 11, 64 bit.

### macOS

macOS paketleri hazır olduğunda sürümün **Assets** bölümünde yer alacaktır.

1. Apple Silicon için `Synapsery_<sürüm>_aarch64.dmg`, Intel için `Synapsery_<sürüm>_x64.dmg` dosyasını indirin, açın ve Synapsery'yi **Uygulamalar** klasörüne sürükleyin.
2. Synapsery'yi açın. "Apple doğrulayamadı" uyarısında **Bitti** seçeneğini seçin (Çöp Sepeti'ne taşımayın).
3. **Sistem Ayarları > Gizlilik ve Güvenlik** bölümünde aşağı kaydırın ve "Synapsery engellendi" satırındaki **Yine de Aç** seçeneğini seçin. Onay penceresinde yeniden **Yine de Aç** seçeneğini seçip Mac parolanızı girin.

Bu onay yalnızca bir kez verilir. macOS 14 ve önceki sürümlerde Synapsery'ye Control tuşuyla tıklayıp **Aç** seçeneğini seçmeniz yeterlidir.

DMG dosyası "hasarlı" olarak bildirilirse dosyayı yalnızca bu sayfadaki resmi bağlantıdan yeniden indirin. Başka kaynaklardan indirilen DMG dosyalarını açmayın.

### Güncellemeler

Synapsery açılışta yeni sürümleri denetler. Güncellemeler tek tıkla indirilir, imzası doğrulanır ve otomatik olarak kurulur.
