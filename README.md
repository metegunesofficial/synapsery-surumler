# Synapsery — indir

**[⬇ Synapsery'yi indir (Windows)](https://github.com/metegunesofficial/synapsery-surumler/releases/latest)**

1. Yukarıdaki bağlantıda en son sürümün **Assets** bölümünden `Synapsery_<sürüm>_x64-setup.exe` dosyasını indir.
2. Dosyayı çalıştır, kurulumu tamamla. Yönetici yetkisi gerekmez.
3. Uygulama açılışta yeni sürümü kendisi denetler; güncelleme tek tıkla iner, imzası doğrulanır ve kurulur.

Gereksinim: Windows 10/11, 64 bit.

---

Bu depo yalnız imzalı kurulum paketlerini ve güncelleme bilgisini (`latest.json`) taşır. Kod gizli depodadır.
